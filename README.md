# XenoVerb Wrapper on Push 3

An interactive map of the Push 3 banks in XenoVerb Wrapper, a free Max for Live device for Audiority XenoVerb. Turn the encoders, press the buttons above the display and switch banks to see what Push shows. No sound, values are simulated.

Open it online: https://julienpbst.github.io/XenoVerbPushWebUI/ (or download `index.html` and open it in a browser).
